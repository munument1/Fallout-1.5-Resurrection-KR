# Fallout 1.5: Resurrection 한국어 번역 KR1.2

하단 메시지 기록창에서 긴 한글 문장의 오른쪽이 잘리던 문제를 수정했습니다. 기존 KR1.1 번역·한글 sfall·글꼴 설정을 유지하고, 한글 줄바꿈을 보완한 고해상도 패치 파일을 포함했습니다.

## 설치

1. 게임을 종료합니다.
2. `RES.korean_msg-V1.5-KR1.2.zip`의 모든 파일과 폴더를 **fores.exe, FALLOUT2, fores.cfg 실제 파일이 있는 Resurrection 실행 폴더**에 덮어씁니다.
3. 기존 `fores.exe` 또는 해당 파일을 가리키는 바로가기로 실행합니다.

바로가기만 있는 상위 폴더와 실제 실행 폴더가 다를 수 있습니다. 바로가기 속성의 대상 경로를 확인하세요.

처음 한국어 패치를 적용할 때에는 기존 `fores.cfg`의 `[system]`에서 `language=korean`을 설정합니다. 이미 한국어로 플레이 중이라면 그대로 덮어쓰면 됩니다.

## 확인 내용

- 기존 번역 및 한글 sfall·글꼴 파일 보존
- 실제 번역문 1,000개, 6개 창 너비, 2개 글자 맞춤 경로 자동 검사
- 총 60,564줄에서 폭 초과·한글 분리 0건
- 실제 게임 메시지창 정상 출력 사용자 확인 완료

# Fallout 1.5: Resurrection 한국어 번역

Fallout 1.5: Resurrection의 한국어 번역 자료입니다.

Fallout 1.5: Resurrection은 Fallout 2를 기반으로 제작된 대형 팬 모드로, Fallout 1과 Fallout 2 사이의 시점을 배경으로 합니다.
무대는 훗날 NCR이 될 지역의 동쪽, 뉴멕시코 일대이며, 기존 Fallout 본편의 지역이 아닌 완전히 새로운 장소와 이야기를 제공합니다.

본 자료는 Fallout 1.5: Resurrection의 게임 내 텍스트를 한국어로 즐길 수 있도록 만든 비공식 한국어 번역 파일입니다.

## 설치 전 준비물

* Fallout 2 본편
* Fallout 1.5: Resurrection English 1.5 archive 버전
* 본 한국어 번역 자료

## 설치 방법

1. Fallout 2 본편을 설치합니다.

2. Fallout 1.5: Resurrection English 1.5 archive 버전을 다운로드합니다.

3. archive 버전의 압축을 Fallout 2 설치 폴더 안에 풀어줍니다.

   예시:

   ```text
   Fallout2/resurrection
   ```

4. 본 한국어 번역 자료의 파일들을 아래 폴더에 붙여넣습니다.

   ```text
   Fallout2/resurrection
   ```

5. 같은 이름의 파일이 있을 경우 덮어씁니다.

6. 게임을 실행합니다.

## 주의사항

* 본 자료는 Fallout 1.5: Resurrection English 1.5 archive 버전을 기준으로 제작되었습니다.
* 다른 버전에서는 일부 문장이 출력되지 않거나, 파일 구조 차이로 인해 정상 적용되지 않을 수 있습니다.
* 기존 세이브 파일과의 호환 여부는 보장하지 않습니다.
* 설치 전 원본 파일을 백업하는 것을 권장합니다.

## 번역 관련 안내

* 게임 내 대사, 설명문, UI 텍스트 등을 한국어로 번역했습니다.
* 고유명사, 지명, 세력명 등은 문맥과 분위기를 고려하여 번역하거나 음역했습니다.
* Fallout 특유의 건조하고 거친 분위기를 살리는 방향으로 번역했습니다.
* 오역, 누락, 어색한 표현이 있을 수 있습니다. 제보해주시면 가능한 범위 내에서 수정하겠습니다.

## 삭제 방법

설치 전 백업해둔 원본 파일을 다시 덮어씌우거나, `resurrection` 폴더를 삭제한 뒤 Fallout 1.5: Resurrection archive 버전을 다시 압축 해제하면 됩니다.

## 저작권 및 권리 안내

Fallout 1.5: Resurrection의 원본 저작권은 해당 모드 제작팀에 있습니다.
Fallout 및 Fallout 2의 권리는 Bethesda Softworks 및 관련 권리자에게 있습니다.

본 자료는 비공식 한국어 번역 자료이며, 원본 게임 또는 모드 파일을 대체하거나 재배포하려는 목적이 아닙니다.
Fallout 2 본편과 Fallout 1.5: Resurrection 원본 모드는 별도로 준비해야 합니다.
